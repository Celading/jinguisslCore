# 0.8.0

中心仓包名为 `jinguissl_core`，直接底层消费使用 `jinguissl_core = "0.8.0"`。
应用优先使用主桥 `jinguissl = "0.8.0"`，由主桥传递引用核心。

- 提供纯仓颉国密算法/PKI/TLCP/DTLCP构件、自有DTLS1.2认证会话与SRTP exporter。
- 修复TLS记录AAD、SSH分组/KDF、证书校验与秘密所有权，以及DTLS认证、重传、乱序和扩展兼容边界。
- 包含公开指南和许可证，不分发单元测试、测试私钥、内部工作记录或本机认证配置。

新增能力、限制和对应证据以能力矩阵为准；DTLS使用可信信令指纹，不宣称完整浏览器/WebPKI覆盖、密码模块认证或恒定时间证明。运行时不链接OpenSSL，独立对端只用于测试。
